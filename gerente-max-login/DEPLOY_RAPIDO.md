# ⚡ Deploy Rápido - GerenteMax Login

## 🚀 **3 MÉTODOS SUPER FÁCEIS**

### 🔥 **MÉTODO 1: Vercel (2 minutos)**

1. **Acesse**: https://vercel.com
2. **Login** com GitHub/Google/Email
3. **Arraste** a pasta `gerente-max-login` para a área de upload
4. **Aguarde** o deploy automático
5. **Pronto!** Você terá uma URL funcionando

### 🔵 **MÉTODO 2: Netlify (2 minutos)**

1. **Acesse**: https://netlify.com
2. **Login** com GitHub/Email
3. **Arraste** a pasta `gerente-max-login` para o Deploy
4. **Aguarde** o deploy automático
5. **Pronto!** URL funcionando

### 📁 **MÉTODO 3: GitHub + Vercel (5 minutos)**

1. **GitHub**:
   ```bash
   cd gerente-max-login
   git init
   git add .
   git commit -m "GerenteMax Login"
   ```
   - Crie repositório no GitHub
   - Faça push do código

2. **Vercel**:
   - Conecte GitHub no Vercel
   - Import do repositório
   - Deploy automático
